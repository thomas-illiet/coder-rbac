2. Set CODER_ACCESS_URL to {{ .Values.config.publicURL }}.
3. Set CODER_WILDCARD_ACCESS_URL to {{ .Values.config.wildcardAccessHost }}.
4. Set coder.envUseClusterAccessURL=false in the official Coder chart.
5. Inject CODER_URL={{ .Values.config.publicURL }} into workspace containers.
6. Ensure workspaces can resolve and reach that public URL.
7. Enforce outside this chart that workspaces cannot reach coderd directly.
